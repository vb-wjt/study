## 3. L 给今年(第三年)的 3 大期望

### 3.1 ⭐ 期望 1:业务广度扩展(摸瓜式学习)

> "你做一件事,**相当于花了三四倍的时间补齐这一块相关的知识** —— 这样做一件事相当于别人做了五件事。"

L 的两个具体例子(可作为脚手架):

```
拿到任务 X →
    顺便了解 X 在 SI 这边怎么做的、卡 [?] 那边怎么做的 →
        相关组件 / 协议 / 上游下游也带着看 →
            形成"做事 + 摸瓜"的复合产出
```

| L 给的例子 | 摸到的瓜 |
|---|---|
| 做新锁(智能锁项目?) | 顺便了解之前**门禁**的接法、特点 |
| 做 vCenter [?wive] | 顺便了解 SI 那边、相关产品组那边 |

> 🎯 **可立即执行**:**为今年的每个新任务,在 docs 里加一段"相关业务摸瓜笔记"**,2-3 个月就能形成体系。

### 3.2 ⭐ 期望 2:专业英语提升(进入绩效)

> ⚠️ "**这是评估你绩效的一部分**" —— L 原话,这是硬指标。

| 维度 | 标准 |
|---|---|
| 目标(年底) | "**工作需要时,可以独立的、不借助软件完成技术沟通**" |
| 对话场景 | 印度测试、欧洲团队、美国 offering、全球客户 |
| **不要做**的 | 学口语 500 句、商务英语 3000 字 |
| **要做**的 | 把日常**后端 / 产品业务上的关键专业词汇**记下来(子类、继承、模拟数据、造数据等) |
| 工具 | 用 AI 工具积累中英对照术语 |
| 评估方式 | "我会观察你在某些会议上,关键的技术词汇能说出来" |

L 的关键洞察:**"技术会议不需要特别流利,但关键词如果说对了,技术会议通常都会带到你"**。

> 🎯 **可立即执行**:开一个 `english-tech-glossary.md`,每周积累 10 个我**真用到**的中英对照术语。3 个月后做一次会议自我录音回放。

### 3.3 ⭐ 期望 3:软技能 —— 会议管理 + 跨国合作

L 把这个列为 **"今年很重要的挑战目标"**(原话)。

#### 3.3.1 会议管理(我主动问 + L 直接答了的部分)

L 的反馈分两层:

**✅ 已做到的**:
- 语言表达比以前简洁不绕
- 准备工作好(数据/表格/PPT/界面)
- 有主题和背景介绍

**⚠️ 需要提升的 —— 主动管理会议进程**:
- "你是主持人,**别人发言过长、偏离主题时,你要敢介入**"
- "你不太自信、不太敢说'我们时间不多,这个事回头单独聊'"
- "**会议结果是你的责任**——任凭别人吹会议会拖到 2 倍时间,该拍就拍"

L 给的会议主持脚手架:

```
会前 (15 分钟):
  □ 我准备了什么材料
  □ 我要抛什么问题
  □ 我希望谁来回答
  □ 出现悬而未决怎么办的预案

会中:
  □ 别人发言偏离 → "我们时间不多,这个事我们单独聊,回到主题"
  □ 该拍板时 → 拍(没把握就把领导拉上,但你能拍就拍)
  □ 决策推进 → 不能让 1 小时 → 2 小时 → 没结论

会后:
  □ 会议纪要 → 同步给项目经理 / 测试 / 跨组的相关人
```

#### 3.3.2 跨国合作(L 主动提的)

L 的原话:**"我会在背面工作上侧重让你去锻炼一下独立地跟老外合作"**。

可能的形态:
- 开会(英文)
- 私下做共同的前后端设计
- 收对方代码 / 给对方代码

> 🎯 这是一个**会主动给我的机会**,我要提前准备好以便不掉链子。
